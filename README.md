# 🍔 Food Delivery App

A food delivery web application built with **React.js** that displays restaurants and food-related content using live data from the Swiggy API.

## 🚀 Live Demo

🔗 https://food-delivery-app-b5xi.onrender.com

## 📌 About the Project

This project is a React-based food delivery application inspired by modern food delivery platforms.

The application fetches restaurant data from the **Swiggy API** and displays it in a clean and user-friendly interface.

## ✨ Features

- 🍽️ Restaurant listing
- 🌐 Live restaurant data using Swiggy API
- 🔍 Search UI
- 🍱 Food category section
- 🧩 Reusable React components
- 🛣️ Multiple pages using React Router
- 📱 Clean and responsive UI
- ⚡ Fast development using Parcel

## 🛠️ Tech Stack

- **React.js**
- **JavaScript**
- **React Router**
- **Parcel**
- **HTML5**
- **CSS3**
- **Swiggy API**

▶️ Run Locally

Clone the repository:

git clone https://github.com/kumar18vardhan/Food-delivery-app.git

Go to the project directory:

cd Food-delivery-app

Install dependencies:

npm install

Start the development server:

npx parcel index.html

The application will run on the local development server.
